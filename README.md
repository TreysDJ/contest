# Contest Preparation

Мой брат сейчас учится в школе и планирует брать олимпиаду по информатике/программированию для поступления в вуз.

Этот репозиторий содержит полезные материалы, roadmap, и прогресс подготовки к олимпиадам.

## Навигация

- [`research.md`](research.md) — методика исследования, анализ трёх официальных сезонов и полная карта знаний;
- [`ROADMAP.md`](ROADMAP.md) — календарный план, зависимости тем и признаки распознавания;
- [`PRACTICE.md`](PRACTICE.md) — проверяемый банк Codeforces/ACMP без искусственной фиксированной квоты, с этапами A0/A1/B/C, ролями и паттернами;
- [`PROGRESS.md`](PROGRESS.md) — уровни освоения, метрики и журнал контестов;
- [`NOTES.md`](NOTES.md) — короткие заметки о полезных идеях, признаках и ошибках;
- [`CONTEST_STRATEGY.md`](CONTEST_STRATEGY.md) — стратегия чтения, переключения, дебага и отправки;
- [`templates/java/`](templates/java/README.md) — компилируемые Java 17 заготовки;
- [`contests/`](contests/README.md) — официальный корпус олимпиадных материалов и манифест полноты.

[`PRACTICE.md`](PRACTICE.md) редактируется напрямую и является единственным источником банка задач. Задачи отбирались
вручную по фактическому способу решения и месту в учебной лестнице; теги и рейтинг использовались только для поиска
кандидатов.

## Проверка репозитория

```bash
# Локальные файлы, Markdown-якоря, корпус олимпиад и Java-шаблоны
python3 tools/audit_repo.py

# То же самое плюс доступность внешних HTTP(S)-ссылок
python3 tools/audit_repo.py --external-links
```

Сетевая проверка считает `404` и `410` подтверждённо сломанными ссылками. Ответы с ограничением доступа, временные
ошибки серверов и таймауты выводятся как `unverified`, потому что они не доказывают отсутствие страницы.
