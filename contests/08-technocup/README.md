# ТехноКубок - исключенный неполный корпус

Официальный архив: <https://techno-cup.ru/archive>.

Официальная страница содержит несколько ошибочных, дублирующих и возвращающих
HTTP 404 ссылок. Из-за системной неполноты официального архива ТехноКубок
исключен из исследования. Частично полученные файлы оставлены лишь для аудита и
**не используются** как доказательная база, источник примеров или частот в
`research.md`, `ROADMAP.md` и `PRACTICE.md`.

Точный журнал проблем приведён в `BLOCKED.md`; контрольные суммы частичных
файлов — в `CHECKSUMS.sha256`.

Статус корпуса: `excluded`.
