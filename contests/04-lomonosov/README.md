# Олимпиада школьников «Ломоносов» по информатике

Официальный архив: <https://olymp.msu.ru/rus/page/main/29/page/zadaniya-olimpiady-proshlyh-let>

## Выбор сезонов

На странице организатора последние доступные материалы профиля информатики —
2022/23, 2023/24 и 2024/25. Поэтому они образуют три последних **официально
опубликованных** сезона этого корпуса.

## Состав корпуса

- 2022/23: отборочный комплект с решениями, два файла задач финала, критерии и
  исходный официальный архив;
- 2023/24: отборочный и финальный комплекты, а также исходный архив;
- 2024/25: пять задач финала 11 класса по отдельности, их объединённая версия,
  критерии и официальный архив с тестами, авторскими программами и работами
  участников.

Отборочный комплект 2024/25 на официальной архивной странице не опубликован.
Вложенный `mats.zip` сезона 2024/25 содержит только материалы заключительного
этапа; индивидуальные `11-task*.pdf` дублируют задачи объединённого
`2025-11-fin.pdf` и сохранены для воспроизводимости исходной публикации.

Все PDF успешно прочитаны `pdfinfo`, все три внешних ZIP прошли `unzip -tq`.
Контрольные суммы находятся в `CHECKSUMS.sha256`.

Статус корпуса: `complete` в пределах официальной публикации; отбор 2024/25 —
`not-published`.
