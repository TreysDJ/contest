# Всесибирская открытая олимпиада школьников по информатике

Официальная страница: <https://sesc.nsu.ru/olymp-vsesib/sections/informatics/>

На официальной странице отсутствует сезон 2023/24. Поэтому в корпус вошли три
последних **официально опубликованных** сезона: 2022/23, 2024/25 и 2025/26.

## Состав корпуса

Для каждого опубликованного этапа сохранены условия группы 9–11 классов и,
когда они опубликованы, официальный разбор:

- `2025-2026/{qualifier,final}/statements-9-11.pdf` и
  `editorial-7-11.pdf`;
- `2024-2025/{qualifier,final}/statements.pdf` и `editorial.pdf`;
- `2022-2023/final/statements-9-11.pdf` и `editorial-7-11.pdf`;
- `2022-2023/qualifier/statements-9-11.pdf`.

Решения основного отбора 2022/23 на официальной странице не опубликованы; это
статус `not-published`, а не ошибка загрузки. Отдельного сезонного блока 2023/24
также нет.

Все 11 файлов распознаны как PDF и успешно прочитаны `pdfinfo`. Контрольные
суммы находятся в `CHECKSUMS.sha256`.

Статус корпуса: `complete` в пределах официальной публикации.
