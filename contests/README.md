# Корпус олимпиадных материалов

Каталог содержит официально опубликованные материалы олимпиад из
`../ru_school_contests.md`. Материалы организованы по олимпиаде, учебному году
и этапу.

Основной диапазон — сезоны `2023-2024`, `2024-2025` и `2025-2026`.
Исключения: для «Ломоносова» используются три последних опубликованных сезона
`2022-2023`, `2023-2024` и `2024-2025`; для Всесибирской — `2022-2023`,
`2024-2025` и `2025-2026`, потому что сезон `2023-2024` на официальной странице
отсутствует.

В корпус включаются условия, официальные решения и редакториалы, критерии,
методические материалы и жюрийские архивы. Рейтинги, приказы, регистрационные
документы и массовые сканы участников не скачиваются.

Сводная информация о полноте и источниках находится в [MANIFEST.md](MANIFEST.md).
