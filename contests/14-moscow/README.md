# Московская олимпиада школьников по информатике

Официальный архив: <https://mos-inf.olimpiada.ru/mosh_past>

В корпус включены материалы для 10–11 классов за 2023/24, 2024/25 и
2025/26. Для каждого сезона сохранены отборочный и заключительный этапы.

## Состав корпуса

| Сезон | Этап | Официальные архивы | Что находится внутри |
|---|---|---|---|
| 2023/24 | отбор | `qualifier/archive.zip` | условия, тесты, ответы и чекеры |
| 2023/24 | финал | `final/problems.zip`, `final/answers-checkers.zip` | единый PDF условий, тесты, ответы и чекеры |
| 2024/25 | отбор | `qualifier/archive.zip` | два вложенных официальных архива с задачами и материалами проверки |
| 2024/25 | финал | `final/full-with-answers-checkers.zip` | исходники условий, PDF, тесты, решения и чекеры |
| 2025/26 | два отбора | `qualifier/full-with-checking.zip` | обе волны, исходники условий, PDF, тесты, решения и чекеры |
| 2025/26 | финал | `final/full-with-answers-checkers.zip` | исходники условий, PDF, тесты, решения и чекеры |

Для 2024/25 и 2025/26 на официальной странице отдельно опубликованы урезанные
архивы «как на туре». Они не сохранены как самостоятельные файлы, поскольку
полные архивы с ответами и чекерами включают те же условия и тесты.

Каждый ZIP полностью проверен командой `unzip -tq`; ошибок сжатых данных нет.
Контрольные суммы находятся в `CHECKSUMS.sha256`.

Статус корпуса: `complete` — все официально опубликованные материалы 10–11
классов за три сезона представлены либо напрямую, либо внутри их полного
официального архива.
