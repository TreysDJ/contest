# Межрегиональная предметная олимпиада КФУ

Собраны официальные материалы основного (заключительного) этапа по
информатике за сезоны `2023-2024`, `2024-2025` и `2025-2026`.

## Источники

- официальный архив: <https://malun.kpfu.ru/mpoarh>;
- официальный файловый сервер КФУ: <https://malun.kpfu.ru/sites/default/files/>.

## Содержимое

- `2023-2024/final/statements-and-solutions.pdf` — единый официальный сборник
  условий и решений для возрастных групп, включая 9-11 классы;
- `2024-2025/final/statements-and-solutions.pdf` — единый сборник задач и
  решений 9-11 классов;
- `2025-2026/final/statements.pdf` и `solutions.pdf` — отдельные официальные
  условия и разбор основного этапа.

Архив КФУ публикует по информатике материалы основного этапа; отдельные
условия отборочного этапа за эти сезоны в архиве отсутствуют. Материалы
2025-2026 уже опубликованы на официальном файловом сервере, хотя общий архив
на момент исследования ещё заканчивается разделом 2024-2025.

Все 4 PDF читаются `pdfinfo`; контрольные суммы находятся в
`CHECKSUMS.sha256`.
