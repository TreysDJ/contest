# Олимпиада «Росатом» по информатике

Официальный архив: <https://olymp.mephi.ru/rosatom_it/training>

Охвачены три последних официально опубликованных сезона: 2023/24, 2024/25 и
2025/26. В PDF находятся условия, разборы и исходные коды авторских решений.

## Состав корпуса

| Сезон | Этап | Файл | Состав |
|---|---|---|---|
| 2023/24 | отбор, 11 класс, волна 1 | `2023-2024/qualifier/statements-set-1.pdf` | 5 задач с решениями |
| 2023/24 | финал, 11 класс | `2023-2024/final/statements.pdf` | 5 задач A–E с решениями |
| 2024/25 | отбор | `2024-2025/qualifier/statements.pdf` | варианты 9–10 и 11 классов; для 11 класса 5 задач с решениями |
| 2024/25 | финал, 11 класс | `2024-2025/final/statements.pdf` | 5 задач A–E с решениями |
| 2025/26 | отбор, 11 класс | `2025-2026/qualifier/statements.pdf` | 5 задач A–E с решениями |
| 2025/26 | финал, 11 класс | `2025-2026/final/statements.pdf` | 5 задач A–E с подробными разборами |

Все шесть файлов получены по прямым официальным ссылкам с архивной страницы
НИЯУ МИФИ. Тип каждого файла проверен как PDF, чтение и число страниц проверены
через `pdfinfo`; контрольные суммы записаны в `CHECKSUMS.sha256`.

## Явно пропущенные материалы

Два уникальных комплекта доступны только после авторизации в Яндекс Контесте и
исключены из корпуса:

- 2023/24, отбор 11 класса, волна 2 — <https://contest.yandex.ru/contest/59547/problems/>;
- 2025/26, финал 11 класса, волна 2 — <https://contest.yandex.ru/contest/87691/problems/>.

Остальные ссылки на Яндекс Контест с архивной страницы дублируют тренировки к
сохранённым PDF и не используются как отдельные источники.

Статус корпуса: `complete-with-gap` — два закрытых комплекта намеренно исключены
из анализа и не будут использоваться как доказательство частотности тем.
