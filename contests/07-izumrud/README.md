# Межрегиональная олимпиада школьников «Изумруд» по информатике

Официальная страница: <https://dovuz.urfu.ru/olymps/izumrud/tasks>

## Состав корпуса

Сохранены официальные объединённые комплекты условий, ответов, решений и
критериев за 2023/24, 2024/25 и 2025/26, а также методическая программа
профиля информатики. Документы включают несколько классов; при тематическом
анализе используются задания 11 класса.

PDF 2025/26 состоит из сканированных страниц без текстового слоя. Он проверен
визуальным рендерингом: раздел 11 класса занимает страницы 1–9 и содержит пять
задач — о побитовых ограничениях, подсчёте двоичных палиндромов, логических
операциях, маршруте по всем рёбрам графа и паросочетании. Остальные страницы
относятся к младшим классам.

Все четыре PDF успешно прочитаны `pdfinfo`; страницы сканированного документа
успешно отрендерены через Poppler. Контрольные суммы находятся в
`CHECKSUMS.sha256`.

Статус корпуса: `complete` в пределах официальной публикации.
