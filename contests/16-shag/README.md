# Олимпиада школьников «Шаг в будущее»: профиль «Информатика»

Официальный архив: <https://olymp.bmstu.ru/ru/variants>

Сохранены задания для 11 класса за 2023/24, 2024/25 и 2025/26. Архивная
страница МГТУ содержит также предмет «Информатика» внутри профиля «Инженерное
дело»; этот параллельный набор не включён, потому что здесь исследуется
самостоятельный профиль «Информатика».

## Состав корпуса

Для каждого сезона сохранены два официальных файла:

- `qualifier/archive.zip` — отборочный этап;
- `final/archive.zip` — заключительный этап.

В 2024/25 и 2025/26 отбор проводится по общему комплекту 10–11 классов, а
финал сохранён именно для 11 класса. В 2023/24 оба архива относятся к 11
классу. Внутри находятся PDF с заданиями, решениями и критериями, а также тесты
и ответы для программируемых задач. В сезоне 2023/24 опубликованы два варианта.

Все шесть ZIP прошли полную проверку `unzip -tq`; повреждённых элементов нет.
Контрольные суммы находятся в `CHECKSUMS.sha256`.

Статус корпуса: `complete`.
