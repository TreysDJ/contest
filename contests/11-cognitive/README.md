# Когнитивные технологии

Собраны материалы трёх последних сезонов: `2023-2024`, `2024-2025` и
`2025-2026`. В каждом сезоне есть три отборочных тура и финал.

## Источники

- официальный сайт и архив: <https://olymp.misis.ru/>;
- сезон 2024-2025: официальные Codeforces Gym `105536`, `105585`, `105618`,
  `105798`;
- сезон 2025-2026: официальные Codeforces Gym `106190`, `106230`, `106269`,
  `106447`.

## Полнота

- `2023-2024`: PDF-условия всех четырёх этапов и опубликованные PDF-разборы
  трёх отборов из официального Google Drive; отдельный разбор финала на сайте
  не опубликован;
- `2024-2025`: условия всех четырёх этапов из официальных Codeforces Gym и
  единственный опубликованный PDF-разбор первого отбора; для финала сайт также
  даёт внешний видеоразбор: <https://vkvideo.ru/video-141534003_456239621>;
- `2025-2026`: условия всех четырёх этапов из официальных Codeforces Gym;
  отдельные разборы организатором не опубликованы.

Codeforces публикует полные условия этих туров как HTML-страницы, а не как
скачиваемый PDF. Файлы `statements-codeforces.pdf` — воспроизводимые печатные
снимки официальных страниц `.../gym/<id>/problems?locale=ru`, созданные
Playwright; число задач проверено перед сохранением.

Все 16 PDF читаются `pdfinfo`; контрольные суммы находятся в
`CHECKSUMS.sha256`.
