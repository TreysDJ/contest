# Вузовско-академическая олимпиада по информатике

Официальные сезонные страницы: <https://sp.urfu.ru/vuzakadem/inform/2026/>,
<https://sp.urfu.ru/vuzakadem/inform/2025/> и
<https://sp.urfu.ru/vuzakadem/inform/2024/>.

Полные условия и официальные разборы трёх туров сохранены за 2024/25 и
2025/26. Материалы 2023/24 доступны только в требующем авторизации Яндекс
Контесте; пользователь явно разрешил их пропустить. Точное описание пробела и
ссылки находятся в `BLOCKED.md`.

Все 12 сохранённых PDF проверены через `pdfinfo`. Контрольные суммы находятся
в `CHECKSUMS.sha256`.

Статус корпуса: `complete-with-gap`.
