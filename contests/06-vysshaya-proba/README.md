# Олимпиада школьников «Высшая проба» по информатике

Официальный архив: <https://olymp.hse.ru/mmo/tasks-it>.

Сохранены условия 11 класса за 2023/24, 2024/25 и 2025/26 и архивы официальных
решений первых двух сезонов. Ссылка на решения 2025/26 заблокирована на стороне
Яндекс Диска; недоступный файл исключен из корпуса. Подробности находятся в
`BLOCKED.md`.

PDF прочитаны `pdfinfo`, ZIP-архивы решений прошли `unzip -tq`. Контрольные
суммы находятся в `CHECKSUMS.sha256`.

Статус корпуса: `complete-with-gap`.
