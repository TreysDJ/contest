# Данные исследования

`codeforces-candidates.json` — воспроизводимый срез кандидатов, полученный 24 июля 2026 года из официального Codeforces API через Playwright. Для каждой из 34 тем сохранены задачи из нескольких рейтинговых диапазонов, их официальные теги и число решивших на дату среза.

Файл не является готовой рекомендацией: итоговая выборка дополнительно проверяется и формируется скриптом [`tools/generate_practice.py`](../tools/generate_practice.py). Скрипт следит за общим объёмом, уникальностью Codeforces ID, приоритетами и ролями задач.
