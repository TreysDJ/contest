# Данные исследования

`codeforces-candidates.json` — воспроизводимый срез кандидатов, полученный 24 июля 2026 года из официального Codeforces API через Playwright. Для каждой из 34 тем сохранены задачи из нескольких рейтинговых диапазонов, их официальные теги и число решивших на дату среза.

Этот файл — только сырой пул для поиска. Тег, рейтинг или число решивших не являются подтверждением учебной ценности задачи.

`practice-catalog.json` — единственный источник окончательной программы. Для каждой выбранной задачи в нём зафиксированы:

- ручная педагогическая роль;
- основной проверяемый паттерн;
- ожидаемый путь решения;
- необходимые предварительные знания;
- причина включения;
- видимость подсказки;
- факт проверки условия и решения.

Schema v2 делит фундамент на этапы A0/A1 и не требует одинакового числа задач или одинакового набора ролей в каждой
теме. CSES, USACO Guide и другие внешние программы используются как карта необходимых паттернов, но обязательные
задачи по принятой политике выбираются только с Codeforces, Codeforces Gym и ACMP.

`practice-audit.md` сохраняет переход от прежнего банка к новому: все 282 старых слота классифицированы как `KEEP`,
`MOVE` или `REPLACE`, а для новой выборки приведена матрица «задача → роль → паттерн → ожидаемое решение». Репозиторный
аудит проверяет, что каждая строка этой матрицы дословно соответствует каталогу, поэтому она не может незаметно
разойтись с `PRACTICE.md`.

[`tools/generate_practice.py`](../tools/generate_practice.py) ничего не выбирает по тегам и не сортирует задачи по рейтингу. Он только валидирует проверенный каталог и детерминированно формирует [`PRACTICE.md`](../PRACTICE.md). Режим `--check` проверяет, что документ не разошёлся с источником.
